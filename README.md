# Manchester United Player Ratings

Plateforme frontend permettant aux supporters de noter les joueurs de Manchester United apres chaque match.

## Scripts

- `npm run dev` : demarre le serveur Vite.
- `npm run lint` : execute ESLint.
- `npm run typecheck` : lance la verification TypeScript.
- `npm run build` : compile TypeScript puis genere le build de production.

Cette premiere version ne contient pas de backend ni de base de donnees. Les ecrans utilisent des donnees temporaires dans `src/data`.
