# Brand Assets

Production-ready local images expected here:

- `favicon.ico`: browser favicon.
- `social-preview.png`: recommended size 1200 x 630 px for Open Graph and Twitter sharing.
- `icon-192.png`: 192 x 192 px PNG for PWA install.
- `icon-512.png`: 512 x 512 px PNG used by the app brand logo and PWA install.

Use only authorised or original assets. Do not use remote images for metadata previews.
