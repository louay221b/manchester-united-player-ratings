# Brand Assets

Place the production-ready local images here before the final public launch:

- `social-preview.png`: recommended size 1200 x 630 px for Open Graph and Twitter sharing.
- `icon-192.png`: required 192 x 192 px PNG for favicon/PWA install.
- `icon-512.png`: required 512 x 512 px PNG for PWA install.
- `manchester-united-logo.png`: local header logo if available.

Use only authorised or original assets. Do not use remote images for metadata previews.
